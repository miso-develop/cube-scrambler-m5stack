Cube Scrambler

M5Stack NanoC6 Web Installer

1Wi-Fi settings

Credentials stay only in this browser page. They are not added to the firmware image or uploaded anywhere.

Enter the Wi-Fi settings that should be applied after flashing.

2Install firmware

Connect the NanoC6 by USB, then install the complete Cube Scrambler image.

This browser does not support Web Serial. Use a Chromium-based desktop browser. Web Serial is unavailable in this page context. Use HTTPS, or localhost for local development.

After ESP Web Tools reports that installation is complete, close its dialog and continue below.

3Apply Wi-Fi settings

Use the same USB-connected NanoC6. The browser will ask you to select its serial port again.

Waiting for Wi-Fi configuration.

4Finish

Installation is complete.
